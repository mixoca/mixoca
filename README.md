## 🔭 Proyectos destacados

- **🏺 TimeTrace** *(FLL 2026)* — Apoyo tecnológico a arqueólogos con IA, datos y dashboard web. ESP32, Sentinel.
- **⚡ Winergy** *(Teleco Games IV 2026)* — Generación termoeléctrica con células Peltier. ESP32 + dashboard en tiempo real con Next.js, Express y Socket.io, desplegado con Docker.
- **☢️ Monitor de radón** *(STEMBACH)* — Sistema completo: firmware ESP32 vía Bluetooth LE, API HTTPS y panel web con histórico, estadísticas y exportación CSV/JSON.
- **🧒 KAEP: pantallas, hábitos y atención** *(STEMBACH)* — Plataforma web (React, TypeScript, Node.js, Docker) con cuestionario y juegos de atención basados en psicología experimental. Diseño anónimo y centrado en la privacidad.
- **🛰️ Montecastelo SAT / CanSat** *(2024 y 2026)* — Software de sonda y nodos de tierra; medición de radiación con contador Geiger.
- **🐋 SilentSeas** *(FLL 2025)* — Barco con hidrófono y Raspberry Pi 5 que clasifica cetáceos con IA a partir de sonidos submarinos.
- **🦶 EnergyStep** *(Teleco Games III / Efigy 2025)* — Baldosa piezoeléctrica que genera energía al caminar, con firmware y panel web.
- **🏊 Naviswim** *(ONCE X Talento / STEMBACH)* — Autonomía para personas con discapacidad visual en piscinas mediante visión artificial.
- **🚨 Detección de caídas para residencias** *(personal, 2024)* — ESP32 + MPU6050, algoritmo en tres fases para reducir falsas alarmas y panel de control con FastAPI y React.
- **📡 Alerta automática de accidentes** *(Teleco Games II)* — Sistema regional de alerta de coche inteligente con LoRa y C++.
- **🌿 Microalgas de espirulina** *(CINvigo 2024)* — Producción de oxígeno en el espacio con ultrasonidos.
- **🧑‍🚀 Astro Pi Space Lab** *(2022-2024)* — Programas en Python ejecutados en la ISS con la ESA.
